# 客席スミ出し iPhone PWA (試作 v2)

## 収録機能
- 各ブロック設定カード右上の「スミ出し」ボタンから直接作業画面へ移動
- 寸法一覧は「列番号 → スミ出し寸法 → 椅子後端」の順で表示
- 日本語UI、iPhone縦画面向け
- 公演データの作成/保存/削除
- ブロック追加、ブロック名・開始寸法・ピッチ・列数・椅子奥行・椅子位置補正
- 前ブロック最終椅子後端 + 通路幅を使う開始位置自動計算
- 手動開始位置
- 正順/逆順の列送り、前/次/最初/最後
- 全列寸法一覧（列番号 → スミ出し寸法 → 椅子後端の順）
- 各ブロック設定カード右側の「スミ出し」ボタンから直接作業画面へ移動
- localStorage保存
- Service Workerによるオフラインキャッシュ

## 計算ルール（試作）
- 列のスミ位置 = 開始寸法 + ピッチ × (列番号 - 1)
- 椅子前端 = スミ位置 + 椅子位置補正
- 椅子後端 = 椅子前端 + 椅子奥行
- 自動開始位置 = 前ブロック最終列の椅子後端 + 前ブロックに設定した通路幅

通路幅の測定基準は現場条件に合わせて検証してください。自動開始寸法は仮ルールです。

## iPhoneへの導入
PWAとしてホーム画面に追加するには、HTTPSで公開されたURLが必要です。
1. このプロジェクトを静的ホスティング（HTTPS）に配置
2. iPhoneのSafariで公開URLを開く
3. 共有ボタン → 「ホーム画面に追加」
4. 「ホーム画面に追加」を確定

zipを展開しただけではiPhoneにインストールできません。HTTPS公開が必要です。
